# Навоий вилояти — Боғланган ягона геоплатформа

Ер участкалари бўйича интерактив геоплатформа. Leaflet харита, туманлар бўйича KPI, қидирув, таклифлар тизими (Firebase Firestore орқали сақланади).

## Ишга тушириш (локал)

1. Файлларни очиш учун **`САЙТНИ_ИШГА_ТУШИРИШ.cmd`** ни икки марта босинг,
2. ёки `navoi_platform.html` ни браузерда локал сервер орқали очинг (масалан `python -m http.server 8080`).

## Асосий файллар

| Файл | Тавсиф |
|---|---|
| `navoi_platform.html` | Асосий саҳифа (UI, логика, Firebase интеграцияси) |
| `sections_data.js` | Бўлимлар бўйича маълумотлар |
| `navoi_geo.js` | Туманлар чегаралари (GeoJSON) |
| `build_geo.py` | **KMZ/KML → `navoi_geo.js`.** Топологик тўғри қуради: тирқиш ва устма-устлик пайдо БЎЛМАЙДИ |
| `fix_geo_gaps.py` | ЭСКИРГАН — эски `parse_kml.ps1` қолдирган тирқишларни ямар эди. `build_geo.py` дан кейин КЕРАК ЭМАС |
| `changed_data.js`, `changed_extra.js` | Ўзгартирилган ер тоифалари |
| `platform_stats.js` | Умумий статистика |
| `leaflet.js`, `leaflet.css` | Харита кутубхонаси |
| `vercel.json` | Vercel деплой созламалари |

## Харита чегараларини янгилаш

Янги KMZ/KML келса:

```bash
python build_geo.py "C:\path\Navoiy.kmz"
```

Бу СИНОВ режими — ҳеч нарса ёзилмайди, фақат нима бўлишини кўрсатади:
нечта объект ўқилди, нечта тирқиш ёпилади, қайси полигон парчаланади ёки
йўқолади, туман номлари эски файл билан мос келадими. Кўнглингиз тўлса:

```bash
python build_geo.py "C:\path\Navoiy.kmz" --apply
```

**Туман номи эски файлдан фарқ қилса ёзилмайди** — платформа Excel
маълумотини харитага ана шу номлар орқали боғлайди, мос келмаса пинлар
йўқолади. Атайлаб бўлса `--allow-new-districts` қўшилади.
Ёзишдан олдин `navoi_geo.js.bak` захираси олинади.

Ёзгандан сўнг `navoi_platform.html` даги `navoi_geo.js?v=...` версиясини
янгиланг — Vercel `.js` файлларини 1 йил кэшлайди.

Талаб: `pip install shapely`

## Firebase

Таклифлар (`proposals` коллекцияси) **Firestore**да сақланади. Лойиҳа: `yer-loyiha`. Оффлайн режимда маълумотлар `localStorage`га тушади, интернет тикланганда автоматик синхронланади.

## Деплой

Сайт **Vercel** платформасига деплой қилинади. `vercel.json` орқали `/` → `navoi_platform.html`.
